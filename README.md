# Local Subtitles（試作）

Macで再生している音声を取得し、端末内で文字起こし・日本語翻訳する字幕アプリです。Apple Silicon、macOS 15以降向けです。

## 使い方

1. このフォルダの `Local Subtitles.app` を開きます。
2. 音声の言語を選び、「開始」を押します。初期設定は英語→日本語です。
3. macOSの音声認識・画面とシステムオーディオ収録の許可に対応します。必要なら許可後にアプリを再起動します。
4. 翻訳用言語データの案内が表示されたらダウンロードします。初回準備にはインターネット接続が必要です。
5. 動画などの音声を再生すると、認識した原文と日本語字幕を表示します。「停止」で音声取得を終了します。

「最前面」で字幕ウィンドウを他の通常ウィンドウの手前に置けます。アプリを終了する場合は Command-Q を使います。

## 端末内処理

ScreenCaptureKitでシステム音声を取得し、Speechの端末内認識を必須にしています。対応していない言語・環境ではエラーを表示し、クラウド認識へ切り替えません。Translationでダウンロード済み言語モデルを使用します。音声・字幕をファイルに保存する処理、外部APIへの送信処理はありません。

## 試作の制限と確認状況

- ビルド、アプリ署名の検証、Info.plistの構文検証を実施しています。GUI操作権限がないため、画面表示、権限許可後の音声取得、実際の翻訳精度・遅延は未確認です。
- 全体の再生音声が対象です。対象アプリの選択は未実装です。
- 端末内音声認識モデルが利用可能である必要があります。利用できない場合は、macOSの音声入力で対象言語を準備するか、別の言語を選んでください。モデルの利用可否は環境に依存します。
- 約50秒ごとに音声認識を再開します。再開時に音声・字幕が途切れる可能性があります。字幕は現在の認識区間を更新表示し、履歴は保持しません。
- 翻訳は認識途中の文も対象にするため、話の進行に伴い字幕が修正されます。遅延は未計測です。
- 保護されたコンテンツ等では音声を取得できないことがあります。
- ローカル用のアドホック署名です。一般配布用のDeveloper ID署名・公証は行っていません。

## 再ビルド

Xcode Command Line ToolsとmacOS 15以降のSDKが必要です。このフォルダで `zsh build.sh` を実行します。ソースは `LocalSubtitles.swift` です。

## 動作確認手順

英語の短い動画を再生し、開始後に原文・日本語が更新されることを確認してください。停止後に更新が止まること、再開できること、60秒以上再生して認識が継続することも確認します。言語モデルの準備後にネットワークを切って同じ確認をすると、端末内動作を検証できます。
